🧭Problems pippin solves

Images don't belong in terminals — until they do. pippin answers “what does this picture look like at 120 columns?” with a single sweep.

🖼️ Three formats, one command

One sweep covers png|jpeg|svg (plus anything Pillow opens: bmp|gif|webp|tiff). Vectors rasterize at 2048px via cairosvg, then downsample — edges stay sharp at high resolutions.

🔤 ASCII or UTF-8

Pick ascii (10 pure 7-bit levels), utf8 (70 levels), or blocks — or bring --custom-chars and tune --contrast / --brightness / --invert.

🎨 Truecolor characters

Every glyph carries its source pixel as an ANSI truecolor foreground. --color for the full effect, --no-color for plain text.

👁️ Preview + export

--preview prints to stdout, -o file writes it down. Both at once, or --no-preview for silent pipelines.

📐 Terminal-aware geometry

Character cells are ~2× taller than wide — --aspect compensates automatically. Set --width 120–240 for high resolution, pin --height when you need exact grids.

⚡ Zero-config + scriptable

pippin in.png just works — utf8 + color + width 100. Exit codes (0/1/2) make it safe in scripts and CI.

🔤Charsets

Three ramps, dark → light. If your terminal can't do UTF-8, ascii still sings.

  • ascii .:-=+*#%@10 levels, pure 7-bit. Safe everywhere.
  • utf8`^", :;Il!i~+_-?][}{1)(|\/tfjrx…70 levels. The high-resolution default.
  • blocks ░▒▓█5 uniform blocks. Posters love it.

Bonus: --custom-chars " .:-=+*#%@" overrides any ramp, and --invert flips it for light terminals.

🚀Quickstart

Full command shape — INPUT is the only positional (preview goes to stdout unless --no-preview is given):

pippin INPUT [-w WIDTH] [-H HEIGHT] [--charset ascii|utf8|blocks] [--custom-chars STR]
pippin INPUT [--color|--no-color] [--preview|--no-preview] [-o FILE] [--invert]
             [--contrast F] [--brightness F] [--aspect F]

Every flag, nothing else:

-w, --width        Output width in chars, 1..2000 (default: 100)
-H, --height       Output height in chars (default: auto, aspect-corrected)
--charset          ascii | utf8 | blocks (default: utf8)
--custom-chars     Custom dark->light ramp, overrides --charset
--color/--no-color ANSI truecolor foreground per char (default: --color)
--preview/--no-preview Print to stdout (default: --preview)
-o, --export       Write rendering to file (parent dirs created)
--invert           Flip the luminance ramp (for light terminals)
--contrast F       Pillow contrast factor (default: 1.0)
--brightness F     Pillow brightness factor (default: 1.0)
--aspect F         Cell height correction (default: 0.55)

Preview (exits 0):

pippin photo.jpg --charset utf8 --width 120
# art on stdout, exit 0

Preview + export — the file keeps ANSI escapes when --color is on, plain text with --no-color:

pippin logo.svg --charset blocks --color --width 80 --export out.ansi
pippin photo.jpg --charset ascii --no-color --width 80 --export out.txt --no-preview
# second form writes the file silently (exit 0)

Help and version both exit 0:

pippin --help
pippin --version
# 0.1.0

📦Install

Each v* tag ships an sdist + wheel (.github/workflows/release.yml) attached to that tag's GitHub Release and published to PyPI — pick your installer:

curl -fSL -o /tmp/pippin-dl/pippin-linux-x64 https://github.com/fluxion-dev/pippin/releases/download/v0.1.0/pippin-linux-x64
chmod +x /tmp/pippin-dl/pippin-linux-x64
/tmp/pippin-dl/pippin-linux-x64 --version
# 0.1.0

gh release download v0.1.0 -p 'pippin-linux-x64' -D /tmp/pippin-dl --repo fluxion-dev/pippin

# 0.1.0

Isolated install from PyPI

pippin on PyPI is a CLI, not a library — pipx installs it into its own venv and puts pippin on your PATH. SVG via pip needs system cairo (see notes below):

pipx install pippin-art
pippin --version
# 0.1.0

Hacking on pippin itself — editable install with dev extras:

git clone https://github.com/fluxion-dev/pippin.git
cd pippin
python3 -m venv .venv && source .venv/bin/activate
python -m pip install -e ".[dev]"
pippin --help

  • Binaries are self-contained — SVG works with no system cairo installed. Linux and macOS: chmod +x the binary after downloading, then run --version to verify.
  • Binaries are unsigned: on macOS run xattr -d com.apple.quarantine on the file first; Windows may show a SmartScreen prompt.
  • macOS builds are arm64 (Apple silicon) only.
  • Prefer pip? That path still needs system cairo for SVG: sudo dnf install cairo pango gdk-pixbuf2 (Fedora) or sudo apt install libcairo2 libpango-1.0-0 libgdk-pixbuf2.0-0 (Debian/Ubuntu).
  • UTF-8 charsets need a UTF-8 terminal; fall back to --charset ascii otherwise. For best quality use --width 120–240 with --charset utf8.

🎨Color & export

Two toggles control the whole output contract — same render, whichever shape your consumer wants:

FlagsOutput
--colorPer-character 38;2;R;G;Bm truecolor + reset per line (default)
--no-colorPlain text, zero escapes — diffable, greppable
--previewPrint to stdout (default)
-o FILEWrite the same rendering to a file (ANSI kept iff --color)
--no-previewSilent mode: export without printing

Same command, different shape — swap the flags, keep the render:

pippin in.png --color -o art.ansi        # replay with: cat art.ansi
pippin in.png --no-color -o art.txt      # plain text artifact

🔢Exit codes & CI gate

Three codes, no surprises — scripts and CI steps can branch on them with confidence.

0 Success

Rendered and previewed/exported — including --help/--version

1 Runtime failure

Missing file, unreadable image, missing cairosvg for SVG input

2 Usage error

Bad --width/--height, unsupported format, or nothing to do (--no-preview without --export)

GitHub Action step

Example config — not executed. Paste it into a workflow to render docs art on every push:

# example config — not executed
steps:

    run: pippin docs/hero.png --charset utf8 --width 120 --no-color --no-preview -o docs/hero.txt
